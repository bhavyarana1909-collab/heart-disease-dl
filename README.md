CardioScan 🫀

CardioScan is a lightweight, frontend-only web application that uses AI to analyze cardiac imaging scans. By connecting directly to OpenRouter's vision models (like GPT-4o or Claude 3.5 Sonnet), it provides instant, structured clinical impressions.

Disclaimer: CardioScan output is AI-generated. It is not a medical diagnosis and does not replace a qualified clinician.

✨ Features

Bring Your Own Key (BYOK): Connects directly to OpenRouter from the browser—no backend required.

Instant Analysis: Upload cardiac scans for real-time structural analysis.

Interactive UI: Features a sleek, clinical dark-mode design.

🚀 Quick Start

Clone & Open: Clone this repository and double-click index.html to open it in your browser.

Configure API: Get an API key from OpenRouter and paste it into the API Source section.

Analyze: Upload a medical image and click "Execute Analysis".

Note: Your API key is stored only in your browser's local memory and is sent directly to OpenRouter.

🛠️ Tech Stack

HTML5, Vanilla JavaScript

Tailwind CSS (via CDN)

OpenRouter API for LMM processing

🌍 Deployment

Drop the project folder into GitHub Pages, Netlify, or Vercel to host it for free instantly.
